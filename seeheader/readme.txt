Responsive WordPress header builder with multiple visual themes, custom action links, WordPress search and an Elementor widget.

== Setup ==
1. Upload and activate the seeheader folder as a WordPress plugin.
2. Open Settings > Header Builder and select a theme, logo and WordPress menu.
3. Add action links and adjust colors and responsive options.
4. Enable automatic display, place the SeeHeader Elementor widget, or use [seeheader].

The included Yekan Bakh font is loaded only on the plugin settings screen. The public header inherits the active theme's font.
